# Security Policy

Please do not disclose credentials, tokens, or exploit details in a public issue.

For vulnerabilities specific to this fork, contact `@kodymullinsx` privately or use GitHub's private vulnerability reporting when it is enabled for this repository. For behavior inherited from the upstream project, report it to the upstream maintainers as appropriate.

When reporting a vulnerability, include the affected version or commit, a concise impact description, and reproduction steps that do not contain live secrets.
